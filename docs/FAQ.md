# 常见问题

**Q：登录后看不到某些菜单？**

A：请联系管理员确认账号角色权限，进入 **用户中心 → 权限管理** 为该角色开启对应菜单权限。

**Q：设备一直显示离线？**

A：检查设备是否正常上电，确认设备使用的协议和平台协议标识一致；查看 **日志管理 → 设备日志** 排查连接失败原因。

**Q：告警规则已配置但未收到通知？**

A：检查告警规则的静默状态是否为“正常”（启用）；确认通知渠道配置正确（短信需绑定手机号、公众号需关注公众号）。

**Q：API 返回 401？**

A：Token 已过期，重新调用 `/iotapi/system/user/app/login` 获取新 Token。

**Q：历史数据查询为空？**

A：确认设备在查询时间段内有正常上报数据；检查时间范围格式是否正确（`YYYY-MM-DD HH:mm:ss`）。

**Q：MQTT 设备连接后很快断开？**

A：检查 clientId 格式是否为 `uzy_1_{addr}` 或 `uzy_2_{addr}`；确认 username/password 与认证方式匹配（一机一证用 dk/ds，一型一密用 pk/ps）；同一 clientId 不能多个客户端同时连接。

**Q：TCP 设备登录报文发出后无响应？**

A：确认报文末尾有 `\r\n`；检查 reg 格式是否正确（逗号分隔，认证类型为 1 或 2）；确认设备地址、dk/ds 或 pk/ps 与平台记录一致。

**Q：TCP 设备频繁断线？**

A：检查是否按时发送 `ping\r\n` 心跳（建议 30～60 秒一次）；排查网络稳定性；查看 **日志管理 → 设备日志** 确认断线原因。

**Q：应用 MQTT 收不到设备数据？**

A：确认订阅 Topic 格式正确（`p/out/{addr}` 或 `s/out/{projectId}/{sceneId}/{addr}`）；确认设备已正常上线且有数据上报；检查 MQTT 连接的 projectId 与设备所在项目是否匹配。
