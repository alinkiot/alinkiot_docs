# 介绍

> 轻量、稳定、开放的工业级物联网管理平台，支持海量设备统一接入、实时监控、数据分析与智能告警。

## 平台简介

alinkiot 是面向工业与企业用户的一站式物联网管理平台。平台采用轻量化分层架构设计，部署简单、运行稳定，内置完备的管理后台，开箱即用。

平台原生支持 **Modbus、MQTT、TCP 透传**等主流工业协议，并通过插件化协议架构支持自定义协议扩展，真正做到“零壁垒”设备接入。配合统一的设备控制、数据分析和告警体系，以及面向 AI 与第三方系统的开放 API，帮助企业快速构建完整的物联网应用。

## 行业背景

物联网在快速发展的同时，也面临以下核心挑战：

| 挑战 | 说明 |
|------|------|
| **多协议互通** | 不同厂商设备使用不同通信协议，难以统一接入与管理 |
| **海量数据处理** | 设备数量激增，实时数据采集与分析对计算能力要求极高 |
| **安全与隐私** | 设备安全机制薄弱，数据传输与存储面临篡改、伪造风险 |
| **弹性扩容** | 业务规模快速变化，平台需具备水平扩容能力应对峰值 |
| **稳定连续运行** | 版本迭代不能中断设备连接，要求无感发布与热更新 |

alinkiot 针对上述挑战进行了系统性的架构设计，提供一体化解决方案。

## 产品架构

针对不同行业设备种类繁多、协议不统一的现实，平台对整个系统进行**分层设计**，将设备通用功能做成标准化、模块化、插件化，同时支持通过插件形式接入第三方平台或私有协议设备。

```
┌─────────────────────────────────────────────┐
│              管理后台 / 开放 API              │  ← 应用层
├─────────────────────────────────────────────┤
│              逻辑层（业务逻辑处理）           │  ← 逻辑层
├─────────────────────────────────────────────┤
│         连接层（协议解析 / 设备连接）         │  ← 连接层
├───────────────┬─────────────────────────────┤
│    存储层      │   设备路由信息 / 会话信息    │  ← 存储层
└───────────────┴─────────────────────────────┘
```

- **连接层**：负责协议解析与设备连接，与业务逻辑完全剥离，网络抖动时可快速扩容
- **逻辑层**：负责业务逻辑处理，独立部署，独立扩展
- **存储层**：负责设备路由信息和会话信息的持久化

## 核心技术优势

### 四层安全体系

| 安全层级 | 技术手段 | 说明 |
|---------|---------|------|
| **安全防御层** | eBPF 技术 | 防止 DDoS 攻击，在内核层面实现高效流量过滤 |
| **通道安全层** | TLS / DTLS / X.509 / ID² | 传输层加密，防止数据在传输过程中被篡改或伪造 |
| **身份安全层** | 多类型设备身份 + 加签认证 | 每台设备具备唯一身份标识，防止身份伪造 |
| **数据安全层** | 多维度隔离（单元/用户/实例） | 用户数据在实例内、用户内、单元内闭环，互不可见 |

平台结合设备行为数据与 AI 能力，对每台设备进行离线安全分析，针对安全等级低的设备自动预警，并对攻击类设备实现**自动拦截**。

### 水平弹性扩容

基于 Kubernetes HPA 实现自定义策略的弹性扩容，根据 CPU / 内存使用率自动调整服务副本数量，连接层因不含业务逻辑，扩容响应极快，可从容应对设备连接峰值。

### 无感发布，零中断迭代

| 机制 | 说明 |
|------|------|
| **连接层与业务逻辑分层** | 连接层发布频率极低，版本更新不影响已有设备连接 |
| **蓝绿发布** | 新旧版本并行，新版本验证通过后平滑切换 |
| **Erlang 热更新** | 运行时直接更新代码，无需重启系统或中断服务 |

### 高性能

- 支持海量客户端同时在线，消息传输极低延迟
- 高并发消息吞吐，可横向扩展
- 支持设备数据高效写入外部存储，历史数据完整可查

### 多协议支持，插件化扩展

| 协议 | 适用场景 |
|------|---------|
| **Modbus-RTU / TCP** | 工业传感器、PLC、仪表等标准工控设备 |
| **MQTT / JSON over MQTT** | 标准 IoT 设备、低功耗无线终端 |
| **TCP 透传 / JSON over TCP** | 自定义报文设备、私有协议终端 |
| **GNSS / 4G** | 定位追踪、信号监测类设备 |
| **自定义协议插件** | 扩展任意非标协议 |
